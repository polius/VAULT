    How VAULT protects your files
    • Nothing leaves this tab. There are no uploads, no analytics and no third-party code. You can check the source on GitHub.
    • Slow to guess. Your password goes through Argon2id with 64 MiB of memory and 3 passes, which makes every guess expensive, even on GPUs.
    • Tamper-evident. Files are encrypted with AES-256-GCM in 1 MiB pieces. Each piece is authenticated together with its position and the file header, so any change, reordering or truncation is detected.
    • Private metadata. The original file name and size are encrypted too. Several files or a folder are packed into one ZIP before encryption.
